# Projeto CRUD de Livros

Este projeto é uma aplicação simples em **React** que permite **cadastrar, editar e excluir livros**.  
Foi desenvolvido com o objetivo de **estudos e prática** de conceitos de front-end, integração com API e manipulação de estados.

---

## Funcionalidades

- **Adicionar livro**: formulário para inserir título, páginas, autor e editora.
- **Editar livro**: ao clicar no ícone de edição, os dados da linha são carregados no formulário e podem ser confirmados.
- **Excluir livro**: ao clicar na lixeira, o livro é removido da lista e da API.
- **Listagem**: todos os livros cadastrados são exibidos em uma tabela interativa.
